# Supplementary Materials Index

This repository provides comprehensive supplementary materials to support the findings of the GPS-Denied Drone Navigation Systematic Literature Review. 

The file `supplementary_materials.zip` located in the root directory contains the following critical artifacts, mapped to their respective manuscript sections:

## 1. Cleaned Dataset
- **File:** `data/processed/database_final_231.csv` and `database_final_231.xlsx`
- **Manuscript Section:** Section II (Methodology) & Section III (Results)
- **Description:** The final curated dataset of 231 papers including extracted statistics, taxonomies, and hardware metadata.

## 2. High-Resolution Figures
- **Files:** `analysis/output/figures/*.png`
- **Manuscript Section:** Section III (Results A–I)
- **Description:** 300 DPI versions of all 9 analytical charts and the PRISMA flow diagram used in the manuscript.

## 3. Statistical Reports & Tables
- **Files:** `analysis/output/report.md`, `analysis/output/tables.md`, `analysis/output/sensor_accuracy.csv`
- **Manuscript Section:** Section III (Results) & Appendix
- **Description:** Detailed statistical breakdown, IQR/Median calculations for ATE RMSE, and clean Markdown tables formatted for publication.

## 4. Complete Bibliography
- **Files:** `references/bibliography.txt`, `references/references.bib`
- **Manuscript Section:** References
- **Description:** Full numbered list of the 231 included studies in strict IEEE format, alongside a BibTeX library for citation managers.

---
*Note: The raw input file (`data/raw/database_original.xlsx`) is excluded from the supplementary ZIP to minimize size, but is fully available in this repository under the `data/raw/` directory.*
