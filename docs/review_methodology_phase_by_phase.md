# Systematic Literature Review – Methodology Phase‑by‑Phase

**Note: This methodology was successfully applied to this GPS-denied UAV navigation systematic review.**

This guide outlines the general phases of conducting a systematic literature review (SLR). It can be reused for any topic.

## Phase 1: Planning

- Define the research questions.
- Identify keywords and search strings.
- Select databases (IEEE Xplore, Scopus, Web of Science, etc.).
- Set inclusion and exclusion criteria (e.g., year range, peer‑reviewed, language).

## Phase 2: Search and Screening

- Perform the search; export results to a reference manager.
- Remove duplicates (using DOI, title, or assigned IDs).
- Screen titles and abstracts against inclusion criteria.
- Obtain full‑text for remaining papers.

## Phase 3: Data Extraction

- Design a data extraction form (Excel/CSV) with key fields:
  - Title, authors, year, venue, DOI, sensor type, navigation method, evaluation metric, accuracy value, environment, etc.
- Extract data from each paper.
- Resolve any ambiguities by consulting co‑authors.

## Phase 4: Data Cleaning

- Deduplicate using a unique key (e.g., Citation Key).
- Handle missing values: either exclude or impute.
- Standardise categorical variables (e.g., sensor types, methods).

## Phase 5: Analysis

- Compute descriptive statistics: counts, percentages, central tendency, dispersion.
- Generate visualisations: bar charts, boxplots, pie charts, trend lines.
- Perform subgroup analyses (e.g., by sensor type, by method).
- Document your findings with researcher remarks.

## Phase 6: Writing

- Structure your manuscript: Abstract, Introduction, Methodology, Results, Discussion, Conclusions, References.
- Integrate tables and figures.
- Interpret findings in the context of the research questions.
- Compare with previous reviews (if any).
- Discuss limitations and future work.

## Phase 7: Verification and Submission

- Double‑check all references.
- Verify consistency between data, figures, and text.
- Request feedback from co‑authors.
- Submit to a journal or conference.

## Tools Recommended

| Tool | Purpose |
|------|---------|
| **Zotero / Mendeley** | Reference management |
| **Excel / Python** | Data extraction and analysis |
| **Google Colab / VS Code** | Scripting and figure generation |
| **Overleaf / Word** | Writing |
